# 共用界面规则（按需并入项目现有设计文档）

- 已明确且应保持的体验、约束 / 不做项：
- 代表场景与主操作 / 最早需要展示的主界面：
- 字体 / 字阶 / 数字排版：
- 项目现有语义变量与真实值：背景、内容层、正文/次要文字、边界、强调/选中；浅深色分别核对。变量集中维护，布局仍按用途决定，不能靠逐页换色或直接复制样例整页完成设计。
- 间距 / 圆角 / 图标：
- 背景 / 材质 / 对比度 / 暗色：
- 选择、输入、导航与过渡：
- 减少动态效果与可访问性：
- 小屏、长文字、空状态、加载与错误：
- 实际查看/操作的相关参考、采用点 / 未采用理由：
- 代表页面的具体决策：内容主次、密度、主操作与反馈；参考特征怎样落实到当前平台，而非只写风格名称。
- 实际渲染与关键操作结果：来源/产物、视口、代表合成内容；已修问题、剩余限制和未验状态，用户认可另列。

采用现有组件规则；不要只用截图或“苹果感”等形容词代替可执行规则。
